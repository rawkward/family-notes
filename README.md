# Наши заметки

Семейный сайт-справочник: квесты (общий список дел), чек-лист, напоминания и разбор автошкол.

Живая версия: https://rawkward.github.io/family-notes/

## Что внутри

- **Квесты** — общий список дел по группам (техника, мебель, ремонт, фото, кошка Киса, здоровье, рутина, досуг). Пункты можно добавлять, править, удалять, отмечать выполненными; группы тоже создаются и переименовываются. Всё хранится на сервере, поэтому телефон, компьютер и планшет видят одно и то же.
- **Чек-лист** — именованные списки покупок и дел (например, «Покупки домой»). Сборы в поездку живут на сайте поездки под паролем. Списки создаются, переименовываются и удаляются; пункты можно добавлять, править, отмечать и снимать отметки. Правки общие для всех устройств.
- **Напоминания** — четыре cron-задачи бота (`family-morning`, `kisa-zhelezo`, `family-ears`, `kisa-magniy`) — только показ; ежегодные даты с обратным отсчётом и регулярные бытовые дела (капли, глисты, уши) — редактируются прямо на сайте.
- **Автошкола** — права как отдельная покупка, школы рядом с цирком с ценами на автомат, телефонами, сайтами, ВК и ссылкой на карту, расчёт «Форсажа» по часам, частники, итог на двоих, рекомендация и скрипт звонка.

Первые данные (группы, чек-листы, даты, регулярные дела) берутся из `assets/notes.js` и один раз засеиваются на сервер скриптом `scripts/seed-live.mjs`; дальше источник правды — база.

## Файлы

```
index.html             разметка, стили и весь рендер
assets/notes.js        стартовые данные и справочник автошкол
assets/api.js          клиент бэкенда: вход, чтение состояния, операции
worker/                Cloudflare Worker + D1 (общее состояние и вход по паролю)
  src/index.js         маршруты: /api/login, /api/state, /api/state/init, /api/ops
  src/state.js         чистая логика: нормализация и операции (её же гоняют тесты)
  src/auth.js          пароль и подписанный токен
  src/cors.js          разрешённые Origin'ы
  schema.sql           таблицы state и login_attempts
scripts/seed-live.mjs  разовый сев живого состояния из assets/notes.js
tests/smoke.mjs        рендер в jsdom + фейковый сервер, «второе устройство»
tests/ops.test.mjs     юнит-тесты операций
```

## Как это работает

Сайт — статика на GitHub Pages. Общее состояние лежит в Cloudflare D1 и доступно через воркер `family-notes-api`
(`https://family-notes-api.rawkward.workers.dev`).

- вход: `POST /api/login {password}` → подписанный токен (хранится в `localStorage` устройства);
- чтение: `GET /api/state` → `{rev, data}`;
- правки: `POST /api/ops {ops: [...]}` → сервер применяет операции и возвращает новое состояние с `rev`;
- клиент раз в 20 секунд (и при возврате на вкладку) сверяет `rev` и подтягивает чужие правки;
- если сети нет, показывается последнее сохранённое состояние и плашка «нет связи»: правка не проходит молча.

Операции: `quest.toggle/add/edit/del`, `group.add/edit/del`, `quests.reset`, `date.add/edit/del`, `regular.add/edit/del`, `cl.add/edit/del`, `cl.item.add/edit/del/toggle`, `cl.reset`.

Пароль и `TOKEN_SECRET` — секреты воркера (`wrangler secret put`), в репозитории их нет.

## Как править

```bash
node tests/smoke.mjs            # рендер, отметки, добавление, «второе устройство»
node --test tests/ops.test.mjs  # логика операций
node --check assets/api.js
git add -A && git commit -m "..." && git push
```

Данные на сайте правятся прямо в интерфейсе. `assets/notes.js` меняют, только когда нужно поправить справочник (автошколы, тексты) или стартовый набор для нового развёртывания.

Pages подхватывает изменения через минуту-две; если открыт старый кэш — жёсткое обновление (Ctrl+F5).

## Деплой

- Сайт: GitHub Pages, ветка `master`, корень. `.nojekyll` обязателен, иначе GitHub съест `assets/`.
- Бэкенд: `cd worker && npx wrangler deploy` (нужен Cloudflare-аккаунт и `wrangler login`).
- Новая база с нуля: `wrangler d1 create family-notes` → `database_id` в `worker/wrangler.toml` →
  `wrangler d1 execute family-notes --remote --file schema.sql` → `wrangler secret put FAMILY_PASSWORD` и
  `wrangler secret put TOKEN_SECRET` → `wrangler deploy` → `node scripts/seed-live.mjs`.
