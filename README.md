# Наши заметки

Семейный сайт-справочник: квесты (общий список дел), напоминания и разбор автошкол.

Живая версия: https://rawkward.github.io/family-notes/

## Что внутри

- **Квесты** — 8 групп из `family-quests/quests.md` (техника, мебель, ремонт, фото, кошка Киса, здоровье, рутина, досуг). Отметки хранятся в `localStorage` браузера: на телефоне и на компьютере прогресс независимый.
- **Напоминания** — четыре cron-задачи бота (`family-morning`, `kisa-zhelezo`, `family-ears`, `kisa-magniy`), ежегодные даты с обратным отсчётом и регулярные бытовые дела (капли, глисты, уши).
- **Автошкола** — права как отдельная покупка, школы рядом с цирком с ценами на автомат, расчёт «Форсажа» по часам, частники, итог на двоих, рекомендация и скрипт звонка.

## Файлы

```
index.html          разметка, стили и весь рендер
assets/notes.js     данные: квесты, задачи бота, даты, школы, расчёты
tests/smoke.js      смоук-тест рендера в jsdom
```

Стиль — тот же, что у `china-trip`: кремовый фон, Fraunces + Inter, вкладки через `#hash`.

## Как править

Данные — только в `assets/notes.js`. Разметку трогать не нужно: всё рисуется из массивов `QUESTS`, `BOT_JOBS`, `DATES`, `REGULAR`, `SCHOOLS`, `TOTALS` и т. д.

```bash
npm i jsdom --no-save     # один раз, для теста
node tests/smoke.js       # проверка, что всё отрисовалось
git add -A && git commit -m "..." && git push
```

Pages подхватывает изменения через минуту-две; если открыт старый кэш — жёсткое обновление (Ctrl+F5).

## Деплой

GitHub Pages, ветка `main`, корень репозитория. Файл `.nojekyll` обязателен, иначе GitHub съест папку `assets`.
